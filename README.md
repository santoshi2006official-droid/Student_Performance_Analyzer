# Student Performance and Attendance Analyzer

## Overview

The Student Performance and Attendance Analyzer is a data analysis project focused on examining academic performance and attendance patterns among students.

The project uses Python-based data analysis and visualization techniques to identify performance trends, compare subject-wise results, examine attendance patterns, and understand the relationship between attendance and academic performance.

## Problem Statement

Educational institutions generate a significant amount of academic and attendance data. Analyzing this data can help identify performance patterns, areas requiring improvement, and possible relationships between student attendance and academic outcomes.

This project analyzes student performance and attendance data to extract meaningful insights through statistical analysis and data visualization.

## Objectives

- Analyze overall student academic performance.
- Compare performance across different subjects.
- Examine the distribution of student marks.
- Analyze student attendance patterns.
- Identify high-performing and low-performing students.
- Investigate the relationship between attendance and academic performance.
- Present findings through appropriate data visualizations.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The analysis is performed using the following dataset:

`Student Academic Performance.xlsx`

The dataset contains academic performance and attendance-related information used throughout the analysis.

## Analysis Performed

### 1. Data Loading and Inspection

- Loaded the student performance dataset using Pandas.
- Examined the dataset structure, columns, data types, and dimensions.
- Checked for missing values and duplicate records.
- Generated descriptive statistics to understand the numerical data.

### 2. Student Performance Analysis

- Calculated overall performance metrics for students.
- Analyzed the distribution of marks.
- Identified students with the highest and lowest overall performance.
- Examined variations in academic performance among students.

### 3. Subject-wise Performance Analysis

- Compared student performance across different subjects.
- Calculated average marks for each subject.
- Identified subjects with comparatively higher and lower average performance.
- Visualized subject-wise performance for easier comparison.

### 4. Attendance Analysis

- Analyzed the attendance percentage of students.
- Examined the distribution of attendance levels.
- Identified students with comparatively high and low attendance.
- Compared attendance patterns across students.

### 5. Attendance and Academic Performance Analysis

- Examined the relationship between attendance and academic performance.
- Compared academic results of students with different attendance levels.
- Used statistical analysis and visualization to identify possible patterns between attendance and marks.

### 6. Data Visualization

- Created appropriate visualizations using Matplotlib and Seaborn.
- Used charts to represent marks distributions, subject-wise performance, attendance patterns, and relationships between variables.
- Interpreted the visualizations to identify meaningful patterns and trends.

### 7. Findings and Interpretation

- Summarized the major patterns observed in the dataset.
- Identified areas of stronger and weaker academic performance.
- Evaluated whether attendance appears to be associated with student academic performance.
- Presented the findings based on the results obtained from the analysis.
